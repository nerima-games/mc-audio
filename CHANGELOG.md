# @nerima-games/mc-audio

## 0.4.0

### Minor Changes

- Move to Effect 4 and mc-kernel 0.9.0. Add branded audio values, result-based validation, and package-owned caption, audio runtime, footstep mapping, and QA APIs. Align weather inputs with `clear`, `rain`, and `thunder`.
  
  Original sample generation now returns `Result` so invalid options, sound IDs, sample rates, and seeds are reported without throwing. Callers must check the result before using a generated WAV or manifest.
  
  The generated declaration comparison found 47 existing callable exports with changed argument or return types, 67 added exports, and no removed exports. Thirty-two callable exports now return `Result`: `canPlayMinecraftFireflyBushIdleSounds`, `createFreeMinecraftMusicManifest`, `createFreeMinecraftMusicPack`, `createMinecraft26_2SoundRegistry`, `createMinecraft26_3Snapshot9SoundRegistry`, `createOriginalSampleManifest`, `generateFreeMusicWav`, `generateOriginalSampleWav`, `minecraftSoundManifest`, `normalizeMinecraftAmbientSoundsDefinition`, `normalizeMinecraftAudioComponent`, `normalizeMinecraftBiomeMusic`, `normalizeMinecraftBiomeMusicDefinition`, `normalizeMinecraftMusicDefinition`, `normalizeMinecraftSoundId`, `parseMinecraftAudioComponent`, `parseMinecraftMobSoundVariantJson`, `parseMinecraftMobSoundVariantRegistry`, `parseMinecraftSoundsJson`, `parseMinecraftWolfSoundDefinition`, `planEndAudio`, `planMinecraftAmbientSounds`, `planMinecraftMusic`, `planMinecraftSound`, `resolveMinecraftMobSound`, `resolveMinecraftMobSoundEventId`, `resolveMinecraftMobSoundVariant`, `resolveMinecraftSound`, `resolveMinecraftWolfSound`, `resolveMinecraftWolfSoundEventId`, `selectMinecraftBiomeMusicDefinition`, and `selectMinecraftSoundVariant`.

## 0.3.0

### Minor Changes

- [#30](https://github.com/nerima-games/mc-audio/pull/30) [`eed60b9`](https://github.com/nerima-games/mc-audio/commit/eed60b9e29c7386ba94dda720bf3ef5dd119395e) Thanks [@takeokunn](https://github.com/takeokunn)! - Require `@nerima-games/mc-kernel` 0.8.0. Consumers must align their kernel dependency to 0.8.0 before upgrading
  mc-audio. The audio package has no runtime API migration for the kernel's 0.8.0 changes, but its compile fixture
  keeps the kernel-owned time and block-id brands at the public boundary. Consumers should run their typecheck with
  the package manager's resolved kernel dependency, pass external audio JSON through the parsers as `unknown`, inspect
  `TonePlayback.accepted`, and call `WebAudioBackend.unlock` from a user gesture.
